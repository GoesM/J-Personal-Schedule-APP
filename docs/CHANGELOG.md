增加八位角色的分肢动作、仅用户拖动移动、今日/长期清单、新增与完成反馈、弹窗自动避让、无声提醒和托盘常驻。复用原有数据与同步入口，主窗口关闭后可继续使用桌宠。Linux 新增 x64 便携包；详见 [桌宠说明](DESKTOP_PET.md)。Android APK 本次保持 1.7.3。

# J人日程APP 1.7.3

修复空闲细线压缩后丢失结束时间刻度：上一日程结束时间标在压缩线上方，下一日程开始时间标在下方。末项显示真实结束时间，隐藏无日程对应的默认 08:00 / 22:00 刻度。保留 6px 无文字空闲线及高度拖动。

# J人日程APP 1.7.2

所有公共空闲时段压缩成 6px 淡色细线，不显示空闲文字，不提供展开操作。鼠标悬停可查看起止时间。包含不足一小时的间隔，保持各日期共用刻度。日程高度拖动及重置保持不变。

# J人日程APP 1.7.1

空闲时间保持自动压缩，移除展开、收起和完整时间轴切换。连续至少一小时的公共空闲仍显示为 32px 静态时间条，日程高度拖动、重置及七日左偏布局不变。旧版 compress-idle 偏好不再生效。

# J人日程APP 1.7.0

- 日程卡片底部增加高度拖动把手；鼠标拖动或触摸拖动均可，聚焦把手后可用上下方向键微调。

- 七日视图改为所选日期前一天、所选日期、后五天；默认所选日期为今天。

验证：25 项自动测试通过，包括拖动、保存、跨日对齐及跨月日期范围；桌面与手机宽度真实指针拖动通过。Windows 成品冒烟测试及 Android 签名验证通过；未进行安卓真机触摸测试。

# 1.0.1

- 新建入口默认日程，TODO区域的加号明确为“＋ TODO”，表单改为显式“日程 / TODO”类型选择。
- 日程强制有效开始/结束时间；TODO隐藏、禁用且清空时间字段，禁止残留时间导致错误分区。

- 前端构建注入浏览器Buffer实现，修复Git索引/提交等阶段的`Buffer is not defined`。
- Git回归测试改为实际浏览器bundle，在初始没有Node Buffer的沙盒内完成真实提交/拉取/推送和多端冲突测试。
- 使用同一应用ID、本地数据目录、数据协议与安卓签名，支持替换升级。

升级：退出旧Windows程序，将新ZIP解压到新目录，运行新EXE即可读取原用户数据与设置。不要手动删除AppData。建议先在旧版导出JSON备份。安卓使用新APK覆盖安装，不能先卸载，否则应用内部数据会被清除。
