# 1.2.0

- 已完成日程/TODO一律浅绿，包括当天和提前完成的事项；未完成日程按本地结束时间过期，无时间TODO按日期过期。
- 启动、每分钟和切回程序时刷新染色，不重建表单或丢失滚动位置。
- 移除课程专用颜色和课程标记表单；旧课程记录继续存在，按普通日程统一染色。
- 每个日期下新增明确“＋日程”按钮，单日视图也提供同样入口；不再用时间格角落的隐蔽加号。
- 日程与TODO都支持前置快捷勾选，点击正文进入编辑，不使用嵌套按钮。
- Windows关闭窗口、安卓返回退出及“退出程序”入口均检查未提交和已提交未推送的本地改动，选择同步后退出或直接退出。
- 退出先等待保存/导入/同步结束；同步失败再次询问是否直接退出，可取消并留在程序中重试。未保存表单也可取消退出。
- 保持应用ID、用户数据目录、操作协议和Android签名不变，支持覆盖升级。

# 1.1.0

- 双端重设计：桌面侧栏 + 自适应七日表格；手机默认单日时间卡片 + 日期条，不再强制横向滚动大表格。
- 保留今天前后七天日期入口、十五日总览、单日视图；翻页步长随视图变化。
- 将设置、帮助、备份、回收站、冲突和颜色说明收纳到侧栏，手机通过“更多”打开。
- 新增 TODO 快速勾选、当日数量与进度；优化编辑表单、手机底部弹窗、空状态和触控尺寸。
- Android 原生容器处理状态栏、导航栏、刘海与键盘安全区域，适配 target 35 的边到边行为。
- 不修改数据协议、同步模块、数据目录和安卓签名；升级保留原有事项及设置。

# 1.0.1

- 新建入口默认日程，TODO区域的加号明确为“＋ TODO”，表单改为显式“日程 / TODO”类型选择。
- 日程强制有效开始/结束时间；TODO隐藏、禁用且清空时间字段，禁止残留时间导致错误分区。
- 旧版本已有事项按时间字段识别；修改日程后写入明确的schedule类型。不自动移动原有TODO、不删除事项。
- 前端构建注入浏览器Buffer实现，修复Git索引/提交等阶段的`Buffer is not defined`。
- Git回归测试改为实际浏览器bundle，在初始没有Node Buffer的沙盒内完成真实提交/拉取/推送和多端冲突测试。
- 使用同一应用ID、本地数据目录、数据协议与安卓签名，支持替换升级。

升级：退出旧Windows程序，将新ZIP解压到新目录，运行新EXE即可读取原用户数据与设置。不要手动删除AppData。建议先在旧版导出JSON备份。安卓使用新APK覆盖安装，不能先卸载，否则应用内部数据会被清除。
