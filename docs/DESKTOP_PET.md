# 桌宠（1.8.0）

Windows 与 Linux 桌面版共用 Electron 桌宠。安卓仍使用原有应用界面，本次不增加 Android 悬浮窗。

## 使用

- 启动后桌宠显示在上次放置的位置；首次在主屏右下角。它不会自动游走。
- 拖住人物移动：手臂和腿随拖动播放动作；按住不动时停步，松手收势后留在当前位置。
- 点击人物打开今日／长期清单。完成按钮可再次点击撤销；正文打开主程序编辑。
- 清单底部可新增当前标签的 TODO；完整日程在主程序新建。新增保存成功播放记录反馈，完成播放庆祝，主界面中的操作同样有效。
- 默认显示五项，可查看全部或显示已完成。新完成的事项暂留在清单中，方便撤销。
- 清单自动放在人物旁边的空位，空间不够时缩短并滚动；拖动期间隐藏，松手恢复，输入不会丢失。“固定”使清单不因失焦收起，但仍会避让人物。
- 右键人物或点击托盘菜单可以打开主程序、调整大小、原地休息、开关提醒、隐藏桌宠或完全退出。主程序“我的工具”也有桌宠开关。
- 桌宠开启时，关闭主窗口会收起主界面；“完全退出”才关闭整个程序，并沿用原有未上传检查。清单未提交的文字也纳入草稿提示。

## 无声提醒

日程开始前10分钟内提醒一次；长期 TODO 在到期或逾期时按当天汇总。气泡不播放声音、不抢输入焦点，支持5分钟后提醒与忽略。提醒记录保存在本机并按数据仓库隔离，重新启动不会重复提醒已经处理的同一项。

提醒依赖程序运行，并非操作系统闹钟。退出程序后不会提醒。完成、冲突、忙碌同步中的事项不会产生新的提醒。

## 数据与维护

所有写入仍由主程序执行；桌宠仅通过受限消息提交新增和完成操作。与主界面共用保存和同步锁；并发更改或冲突会要求刷新/进入主程序处理，不覆盖新版本。主窗口隐藏时仍保留数据控制器。

人物与动作源文件在 `../../J人形象设计/src/pet-*`；导出资源在 `../../J人形象设计/pet/`。构建脚本复制到 `assets/pet/` 并记录 SHA256 和来源版本，程序内副本不可手改。没有相邻素材目录时，使用仓库中已经校验的资源快照。

桌面代码：`desktop/pet/host.cjs` 管窗口、拖动、托盘、点击穿透；`geometry.cjs` 管弹窗放置；`reminders.cjs` 管提醒条件；`src/pet/` 管桌宠和清单页面；`src/pet-model.mjs` 和 `pet-integration.mjs` 将操作接到原有存储。

## Ubuntu

发行包是 x64 的 tar.gz，解压后运行 `j-personal-schedule`。如果解压工具未保留执行权限，先为该文件执行 `chmod +x j-personal-schedule`。需要 GTK/NSS 等常规桌面依赖，以及用于保存同步凭据的系统密钥环（例如 GNOME Keyring）。若密钥环不可用，离线任务仍可使用，同步配置会明确提示，程序不会降级为明文保存令牌。

Wayland 会限制 Electron 窗口定位。检测到 Wayland 且存在 DISPLAY 时，应用使用 XWayland；也可从 Ubuntu 登录界面选择 Xorg 会话。没有 XWayland 的纯 Wayland 环境尚不作为完整桌宠支持环境。WSLg 测试不能替代 Ubuntu GNOME 实机中的置顶、托盘、多显示器验收。

## 验证命令

- `npm test`：存储、Git双设备同步、模型和桌宠操作/布局/提醒规则。
- `electron scripts/pet-smoke.cjs`：三个真实隐藏窗口、独立临时数据，验证新增/完成、动作、拖动、点击穿透、弹窗与生命周期。
- 成品加 `--pet-self-test`：仅在临时目录运行桌宠功能自检并退出；不使用真实数据。
- `npm run package:win` / `npm run package:linux`：构建 Windows ZIP 与 Linux tar.gz；Windows 自动维护固定快捷方式。
