# 1.0.1 修复与回归记录

- 新建默认日程、TODO加号默认TODO；表单明确选择类型。
- 日程保存必须有有效时间范围；TODO隐藏、禁用并清空时间。
- 修复浏览器Git缺失Buffer，不启用不安全的Node renderer权限。
- 七项测试通过：实际前端DOM表单分区和类型互转、表单时间语义和校验、浏览器VM中真实Git提交/拉取/推送/并发冲突、模型与五色、时间轴重叠。
- 保持应用ID、用户数据位置和数据协议；无批量数据迁移，不自动修改用户现有事项。
- Windows成品自检同时验证浏览器Git通过原生文件桥接创建索引和提交。

退出旧版后再运行新EXE。建议先导出备份。之前误存为TODO的日程可编辑、切换为日程、补全时间。APK使用原签名覆盖升级，尚无真机验收。
