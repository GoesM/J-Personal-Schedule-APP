# J人小程序 1.1.0 · 双端界面升级

日期：2026-09-18。

## 改动

- 统一为浅底色、深青绿色主色、柔和卡片和清晰的分组层级。课程及事项五色规则保持原样。
- Windows 默认七日视图、较均衡的窗口比例；侧栏集中放置统计、设置、帮助、备份、回收站、冲突与颜色说明。时间轴使用可用高度，并优先压缩无日程的区段。密集的安排允许滚动，避免强行挤压重叠。
- 手机默认单日时间卡片，上方日期条仍覆盖前后各七天；搜索按需展开，低频功能收进“更多”，右下角提供新建入口。日程和无时间 TODO 分区展示。
- 两端均可切换单日、七日或十五日总览。翻页步长随视图变化；TODO 方框可以直接勾选完成，标题点击进入编辑。
- 手机编辑框改为底部弹窗，增大触控区域；Android 原生容器处理状态栏、导航栏、刘海和键盘安全区域。
- 数据格式、本地数据目录、Git 同步协议、应用ID及Android签名均保持不变，不自动移动或改写既有事项。

## 已验证

- 7项自动测试全部通过：日程/TODO类型与时间校验、颜色/日期、重叠分栏、并发修改、实际浏览器Git提交/拉取/推送，以及表单入口与双端视图切换。
- Chromium 实际渲染1320×900、390×844、360×740，页面无整体横向溢出。手机日程卡片宽度分别263px、247px，顶部占用约242px；编辑弹窗不超出屏幕，更多菜单可见。
- Windows 1.1.0 成品EXE隐藏烟测：增改删与恢复、重读、导入去重、加密设置、仓库切换保留事项、浏览器Git提交及15日日期入口全部通过。
- Android APK：版本1.1.0 / versionCode 3，构建通过，v2/v3签名通过，沿用已有签名材料。
- 最终Windows ZIP通过7-Zip完整性检查，包含EXE及app.asar；ZIP未包含用户日志、加密设置或签名私钥。APK含新UI且不含示例数据桥。校验值见 `SHA256.json`。
- 视觉截图见“界面预览”目录。截图使用临时示例数据，不代表你的实际课表内容；示例数据不会进入安装包。

## 升级

建议先在旧版导出JSON备份。Windows退出旧版后，把 `J人小程序-1.1.0-win.zip` 解压到新目录，运行其中EXE；不要只复制EXE，保留全部文件。无需复制旧程序目录中的文件，用户事项和设置仍在原AppData目录。

Android使用 `J人小程序-Android.apk` 直接覆盖安装；不要先卸载，否则内部数据将被删除。当前无连接真机，APK构建、签名与手机宽度渲染检查不等同于已完成Android真机验证。请在手机确认系统栏避让、键盘输入和覆盖安装后的原数据。

浏览器与电脑操作预览工具本次启动失败，改用应用自身的隔离离屏Chromium渲染验收。没有操作你的旧版窗口或真实数据。
