# J人小程序 1.2.0 修复与验收

日期：2026-09-18。

## 功能

- 已完成日程/TODO一律浅绿，包括当天和提前完成的事项。未完成日程按本地实际结束时间过期；没有时间的TODO按日期过期。启动、每分钟及切回应用时刷新，颜色刷新不改变记录、不关闭表单。
- 移除课程特殊颜色、颜色说明及课程表单标记。旧课程记录不删除、不批量改写，按普通日程统一渲染；编辑保存后写入schedule类型，标题、地点等信息照常保留。
- Windows每个日期表头下提供“＋日程”；手机单日行程中也提供同名入口。所有日程和TODO均有独立的前置勾选按钮，点击正文编辑。
- 正常关闭Windows窗口（包括Alt+F4）、安卓返回退出或点击“退出程序”，先等待保存/导入/同步完成，再离线检查本地未上传的改动。未提交的工作区/索引改动以及本地提交但尚未推送的提交都包括在内。
- 无待上传改动直接退出；有改动时可选先同步再退出，或不再同步直接退出。同步失败会再次询问是否直接退出，也可以取消以留在应用重试。状态读取失败同样需要明确确认。未保存表单可取消退出。
- 保持本地数据目录、操作协议、应用ID及Android签名不变。

## 升级与边界

建议先导出备份。Windows退出旧程序后，把 `J人小程序-1.2.0-win.zip` 解压到新目录，运行其中EXE，保留所有配套文件。旧事项和设置仍在AppData目录，无需手动搬移。

Android用 `J人小程序-Android.apk` 直接覆盖安装，不要先卸载。本轮未进行Android真机验收，请确认返回退出提示、键盘/系统栏和原数据。系统强制杀进程、Windows任务管理器结束进程或安卓划掉后台任务无法保证弹出退出确认；这类操作之前请主动同步。离线退出检查使用本地最后已知的origin跟踪引用，不会在退出询问前访问网络，也不等于实时检查远端仓库被其他工具重置的状态。
