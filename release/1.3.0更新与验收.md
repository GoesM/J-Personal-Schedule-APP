# 1.3.0 · 长期 TODO 与三类别界面

本地成品：`J人小程序-1.3.0-win.zip`、`J人小程序-Android.apk`。

## 功能与数据

- 三类别：有时间范围的日程、只有日期的单日 TODO、可不填 DDL 的长期 TODO。
- 长期未完成按 DDL 升序，无 DDL 独立显示；已完成默认折叠，只展示本地今天及前六天。
- 未完成按设备维护工作集，已完成按完成月份分文件；轻量因果索引保留版本关系。常规加载不读取旧月份，完整备份按需包含更早完成与删除记录。
- 完成、恢复、并发编辑和冲突解决均保留因果关系；索引提交前后故障不会破坏已保存版本。
- Windows 右栏长期清单，左栏日程 / 单日 TODO；时间区独立滚动。安卓“每日安排 / 长期 TODO”分页面。
- 七日导航、日程与 TODO 列共用列宽和横向滚动；移除十五日日程视图。
- 跨日期自动更新七天窗口和今天标记，保留打开的编辑草稿。
- 原有日程日志保留，旧 JSON 备份继续可导入；v2 备份包含长期类别。

数据细节见 [存储设计](../docs/LONG_TODO_STORAGE.md)，操作见 [使用指南](../docs/USAGE.md)。

## 升级

Windows 退出旧程序，将新版完整解压到新文件夹后运行其中 EXE，沿用原用户数据目录；保留同目录运行时文件。安卓直接用新 APK 覆盖安装，不先卸载。使用长期 TODO 的同步设备都建议升级到 1.3.0，旧版不显示或导出该类别。

旧版 Windows 包保留。新版覆盖的旧 Android APK 已保留在 `release/android-1.2.0/`。本轮未发布远端 Release，也未改动个人数据仓库。
