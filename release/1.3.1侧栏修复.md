# 1.3.1 · 恢复桌面侧栏文字

此前桌面侧栏被缩为纯图标栏，按钮和颜色说明的 `font-size: 0` 使文字不可见。本版恢复常驻的“图标 + 文字”，同时恢复品牌、工具标题和颜色规则说明，保留悬停提示。

侧栏固定 208px，七日安排和长期 TODO 栏重新分配宽度；窄桌面仍保留文字，安排区域可以横向滚动，日期 / 日程 / TODO 列一起移动。侧栏超出窗口高度时可滚动。

隔离 Chromium 检查通过：1320px / 1000px 桌面的七个功能文字均有实际字形尺寸、字号至少12px、不截断；颜色说明可见；日期与日程、TODO列在滚动前后差小于1px。390px / 360px 手机布局与操作检查通过。

Windows 完整解压新版 ZIP 后运行同目录内的 EXE，沿用已有数据和配置。APK 同步递增到 1.3.1 / versionCode 6，沿用签名。未修改业务或数据协议。
