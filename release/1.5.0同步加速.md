# 1.5.0 同步加速

本版保留原有 Git 仓库、数据协议、应用ID与安卓签名，可覆盖安装。

## 实施内容

- 原生 `readBatch` 每次读取最多32个历史文件，避免每个操作单独往返 WebView。1000个文件的内容读取从1000次桥调用降到32次（不含目录、长期TODO、Git操作）；数据量没有减少。
- 每次仍检查本地实际工作区，但干净时跳过 add；服务器确认 HEAD 一致时只查询远端，不再下载、检出、重载或推送。
- 一次同步共享 Git 缓存，结束即丢弃，不跨设备/仓库复用。
- 合并后 HEAD 未变化时不重新检出或加载；仍有新远端数据时采用批量完整读取，暂不依赖持久化历史缓存。
- 界面显示当前同步阶段；操作指南里显示最近同步的总耗时、各阶段耗时和桥调用数。摘要只含数字、阶段与成功状态，无日程内容或凭据。
- 保存检出中断标记，重试时先尝试恢复；遇到本地编辑不强制覆盖。

## 范围与验证

本版没有引入 JGit、删改 Git 历史或更改长期TODO归档结构，也未跳过冷启动工作区检查。无变化拉取仍有一次本地扫描和一次网络查询，不能承诺瞬间完成。

真实本地 smart-HTTP 回归检查无变化仅一次HTTP查询且不重载，以及双端离线修改、冲突解决、推送失败重试和长期TODO同步。此处桥调用下降是代码与自动测试结果，不是真机加速倍数。安卓真机网络和存储性能仍需使用本版帮助页的计时结果评估。
