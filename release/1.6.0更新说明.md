# J人日程APP 1.6.0

Windows 入口：本目录 `J人日程APP.lnk`。完整便携包为 `J人日程APP-1.6.0-win.zip`，快捷方式由打包流程生成并更新。移动整个release目录后，应重新运行 `scripts/release-shortcut.ps1 -Version 1.6.0`。

日程采用统一分钟比例：4小时与1小时为4:1；9:00–12:00为3小时，与1小时为3:1。长时间轴可上下滚动；短日程不再为文字单独撑高，点开查看完整信息。

拖动“当日日程”和“当日TODO”间的横条可调整可见高度；方向键可微调、双击恢复默认。比例保存在当前设备，不改变日程时间比例。同步状态移到页面顶部，不再插在日期和日程之间。

不再提供回收站或逐项恢复。新删除操作只写不含原题目、地点和备注的删除标记，以防旧设备将事项带回。此前已经存在的历史操作、备份和Git提交不会被重写；这不等于从历史仓库中安全擦除所有旧内容。

改名保留 `j-personal-schedule` 用户目录、`cn.goesm.jcalendar` 应用ID和Android签名，覆盖升级沿用现有数据。
