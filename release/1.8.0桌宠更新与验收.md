# J人日程APP 1.8.0：桌宠

日期：2026-11-12。[GitHub Release v1.8.0](https://github.com/GoesM/J-Personal-Schedule-APP/releases/tag/v1.8.0) 提供 Windows 与 Linux 成品。Android APK 保持 1.7.3，作为配套下载单独标明版本，不包含桌宠功能。

## 功能

- 八位 J 型角色均使用原图矢量分肢动作，包含拖动行走、原地待机、点击回应、新增记录、完成庆祝、休息和松手收势。
- 仅用户拖动改变角色位置，不自动游走。拖动途中停住则停步，松开后留在原位。
- 今日／长期清单、日程起止时间、截止日期、勾选完成与撤销、快捷新增，以及跳转主程序编辑。
- 弹窗四向避让人物；拖动时暂时隐藏并保留输入。透明空白区域不拦截鼠标。
- 主窗口收起后继续使用桌宠，托盘可完全退出；退出沿用同步检查并纳入桌宠输入草稿。
- 无声日程和长期 TODO 提醒，可延后5分钟，处理记录按仓库隔离并保存在本机。

## 验证边界

WSLg 不是 Ubuntu GNOME 实机；原生桌面的置顶、托盘、多屏、缩放以及硬件鼠标手感仍需现场验收。原生 Wayland 无 XWayland 环境未列为完整支持。

此 WSL 环境没有 GNOME Keyring，因此同步凭据加密保存未在 Linux 环境验收；程序会明确提示密钥环不可用，不将令牌降级为明文。Windows 的加密配置自检与现有 Git 同步回归已通过。

动画为二维矢量关节动画，保持原有人物外貌和道具；后续可继续在 J人形象设计中细调步态。未声称使用三维骨骼或物理模拟。
