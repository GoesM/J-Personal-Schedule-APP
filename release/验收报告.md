# J人小程序 1.0.0 验收记录

日期：2026-09-17。

## 已通过

- 纯模型测试：五色规则、今日/跨年日期、并发版本保留与解决、链式重叠日程分栏。
- 实际本地 Git smart-HTTP：空仓库初始化、提交/拉取/推送、两端离线独立新增、并发编辑、冲突解决回传。
- Gitee 实联调：用户指定仓库私有状态确认、鉴权、临时分支推送、第二端拉取与修改、第一端获取修改。临时分支已删除，main为默认分支，main只包含FORMAT标记。
- Windows 原生测试：隐藏启动、真实文件IO、增改删/恢复/重读、导入去重、凭据加解密、仓库切换保留事项、15天界面加载。
- Android：Java/dex构建、APK资源完整性、apksigner v2/v3签名验证。

## 仍需用户真机验收

安卓手机安装、WebView兼容性、触屏编辑、系统文件选择与备份导出、跨设备同步。当前无连接手机，不能把编译与签名通过等同于真机验证。

Windows发行包未使用可信发布者代码签名，可能触发未知发布者提示；安卓签名为本项目本地签名。没有实现系统通知闹钟、XLSX自动迁移或端到端内容加密。已有Excel未被本次开发修改。

访问令牌仅在各设备应用设置中输入并本地加密，不进入源码、备份或成品。若令牌曾被泄露，请及时撤销并更换。所有设备使用相同的数据仓库与分支。
